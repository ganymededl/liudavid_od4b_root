# Model Mission Control Azure deployment runbook

The complete administrator runbook is published with Model Mission Control:

`../model-mission-control/azure-deployment-runbook.html`

It covers:

1. Azure AI account and model deployment
2. Entra protected API registration and delegated scope
3. Entra SPA registration, redirects, permissions, and preauthorization
4. Linux Flex Consumption Function App on Node.js 22
5. System-assigned managed identity and least-privilege Azure AI role
6. Required application settings and exact-origin CORS
7. Function deployment and frontend configuration
8. End-to-end validation, troubleshooting, and rollback

The public page includes sanitized portal checkpoint visuals. Use deployment-specific values from your tenant; never copy identifiers from another environment.
