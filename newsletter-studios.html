NL Studios

Looking for the studio itself? The NL Studios card on the Hub now opens NL Studio directly in the browser — no download needed. This page is the version history and offline download archive.

NL Studio turns plain text blocks into an email-client-safe HTML newsletter for the US SLED CSU Review / IMPACT monthly edition. It runs entirely in your browser — no backend, no account, nothing uploaded. The current build enforces the Review house rules (one primary CTA, bolded takeaways, the fixed customer-win template, one dated list) with a live preflight check. Earlier builds are preserved unchanged for comparison.

Hosted preview vs. downloaded copy. Opened from the Hub, NL Studio runs inside OneDrive’s sandbox: it works, but that sandbox blocks browser storage, file downloads and remote images. Drafts are not kept between visits, the live preview shows image placeholders, and Download .html hands you the HTML in a copy box instead of saving a file. None of that affects the newsletter itself — the exported HTML still contains every image. Download the file below and open it from your machine for draft saving, real downloads and full preview images.

NL Studio v3 — Review house rules

The flexible engine, now built around the SLED CSU Review editorial rules instead of leaving them to memory. One primary CTA stated as “This month’s one thing” directly under the masthead, a bolded takeaway on every section, leadership capped at three bullets, the fixed Summary / Background / The Win / What’s Next / Why It Matters win template, people and culture as a compact list, and every event and training deadline consolidated into one chronologically sorted dated list. A live preflight panel runs the “before finalizing” checklist on every keystroke, including Gmail’s 102 KB clipping limit.

Readability: 16 px body and list copy, 14 px secondary, nothing below 11 px, and no type reduction on mobile — matched to the CSUReviewv1.1 standard and enforced by 211 automated checks.
