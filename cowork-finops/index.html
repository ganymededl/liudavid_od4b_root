Cowork FinOps Quickstart

Generating a Copilot Cowork credit cost report, end to end, against a live tenant. Written up October 28, 2026 using Microsoft's public Analytics Hub — Cowork Billing templates and browser tools.

This walks through pulling the two tenant exports, running the free FinOps browser report (no install), reading the output, and — if you want the deeper departmental view — opening the companion Power BI templates. Every screenshot below is from a real run against a Microsoft test/lab tenant with synthetic users; no customer data is shown.

Nothing you upload leaves your browser. The FinOps report and the Cowork Billing browser tools run 100% client-side — no server, no upload, no telemetry of file contents. You can verify this yourself: open DevTools → Network tab while using the tool and watch that your CSVs never appear in a request.

01Start at the Cowork Billing hub

Everything lives off one page: microsoft.github.io/Analytics-Hub/cowork-billing. It lists the Power BI templates (Consumption Central, Cowork Chargeback) and the no-install browser tools (Chargeback, FinOps & FOCUS, ROI Model, Policy Helper).

If you only need the Power BI templates, grab them directly from GitHub — no sign-in required:

  • Consumption Central - Local CSV.pbit — download (also has Fabric and live Viva Direct Query variants in the same repo)
  • Cowork Chargeback - CSV.pbit and Cowork Chargeback - Direct Query.pbit — download

02Export your two tenant files

The FinOps report (and the Chargeback tool) both read the same two exports:

ExportWhereGives you
Entra usersEntra admin center → Identity → Users → All users → Download usersDepartment, Cost Center, Business Unit, Job Title, Country, Manager — the allocation dimensions
Copilot credit usageMicrosoft 365 admin center → Copilot → Cost management → Consumption → Export CSVOne row per user: credits used, credit limit, license status, last activity, session count

Column names are auto-detected by the tool, so most export layouts work unmodified. Both files are plain CSV — open them in Excel first if you want to sanity-check row counts before loading.

03Load both files into the FinOps report

Open the tool and drop each file in its own zone — Entra export on the left, Copilot credit export on the right. The Generate FinOps Report button stays disabled until both are loaded.

There's also a Fallback credit limit field, used only if your credit export is missing a per-user limit column — leave the default unless you know your tenant's policy limit differs.

04Click Generate and read the report

The two files join on User Principal Name and the page renders a full FOCUS-aligned cost view: scope strip, live rate controls (List vs. Contracted unit price), KPI band, cost-allocation cut (department / cost center / business unit, searchable and filterable), rate-comparison bars, and a methodology/glossary section.

Read the overage notice on the page. Per-user spending-limit overage is, at Microsoft's sole discretion, not billed and does not appear as consumed credits — so any "overage" figure here is a planning estimate, not a reconciled bill. The policy-level budget is the real hard stop. Always reconcile the Billed cost figure against your actual Microsoft invoice.

06Optional: go deeper in Power BI

The browser tool is a fast first read. For recurring, refreshable reporting — departmental chargeback with billing-model comparison, prepaid pool allocation, per-user watchlists, row-level security, or a cross-product view spanning Cowork + Copilot Studio + GitHub Copilot + Azure AI Foundry — open the matching .pbit template in Power BI Desktop and point it at the same two CSVs (or Fabric / live Viva Direct Query, depending on the template).

  • Consumption Central — one model across four products, synthetic sample data ships with it so you can see the whole report before touching a tenant.
  • Cowork Chargeback — three billing models priced side by side (pay-as-you-go, prepaid, hybrid), prepaid pool allocation, per-user watchlist, row-level security, FOCUS cost view.

Notes & methodology

  • FOCUS-aligned: List / Contracted / Effective / Billed cost, same vocabulary as the sibling Chargeback tool.
  • Showback = full effective cost of consumption per unit; Chargeback = over-allowance credits × contracted rate.
  • Single-month snapshot — no amortization, forecasting, or anomaly detection in the browser tool (that's what the Power BI templates add).
  • Both CSV exports are required; the tool will not generate a report from Entra data alone or credit data alone.
  • Questions or feedback on the methodology: copilot-roi-advisory-team-gh@microsoft.com.
