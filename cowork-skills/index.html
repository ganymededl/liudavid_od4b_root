Cowork Skills

Two companion custom skills for Microsoft 365 Copilot Cowork: estimate the personal time/dollar value your own Cowork use represents, then net that estimate against what your current billing period's credits cost. Public download — no sign-in required.

🌐 Public download — no Microsoft sign-in required

Cowork Value Report

Reconstructs your own Cowork business-value ESTIMATE by reading your OneDrive Documents/Cowork/Tasks folder (or a pasted/attached task list as a fallback): separates recurring automation runs from one-off tasks, classifies each task into one of 8 categories, applies Cowork effort-band minutes, and outputs a summary table, an itemized CSV, a multi-tab Excel workbook, and an offline HTML chart report. Every number is an estimate built from effort bands — never billed, metered, or measured savings.

Cowork custom skill (SKILL.md + Python) Personal use — your own tasks only Validated in Commercial M365 ~43 KB zip
Download cowork-value-report.zip

Trigger phrases once installed: "run my Cowork value", "reconstruct my use cases", "estimate my Cowork hours saved".

Cowork Net Value

Companion to Cowork Value Report. Finds the newest value-report CSV for the current calendar month, sums this month's scored one-off tasks at a standard hourly rate across Low/Mid/High bands, asks once for your credit count and $-per-credit rate, and returns a NET verdict per band plus a one-row CSV and an Excel workbook (Results and Legend tabs). Refuses a CSV from an earlier month so the net figure always matches the current billing period.

Cowork custom skill (SKILL.md + Python) Requires Cowork Value Report run first Current billing period only ~16 KB zip
Download cowork-net-value.zip

Trigger phrases once installed: "net my Cowork value", "Cowork net savings", "what did Cowork actually cost me net of savings".

How to install

  1. Download the zip(s) above — each one already contains a SKILL.md plus its scripts/ folder, unzipped.
  2. In Copilot Cowork, open Settings → Skills and choose to add or upload a custom skill.
  3. Upload the downloaded zip directly (no need to re-zip or rename anything).
  4. Run Cowork Value Report first each month before Cowork Net Value — the net skill reads its CSV output.

Both skills only ever read the signed-in user's own OneDrive task history and produce personal estimates — never another person's data, and never billed or measured figures.

Both skills are plain-text SKILL.md + Python bundles — safe to inspect before installing. Figures they produce are always estimates, not billed or metered savings.
