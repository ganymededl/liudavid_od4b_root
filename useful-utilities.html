Useful Utilities

Small, self-installing Windows tools built for day-to-day M365 workflows. Each installer is a standalone Inno Setup package — no separate runtime install required.

🔒 OD4B / Microsoft sign-in required to download

Extract Transcript

Pulls the complete transcript from a Microsoft Stream / SharePoint meeting recording — even when the "Download transcript" button is greyed out because the recording is organizer-only. Signs in as you and calls the same media API your browser uses to render captions, then converts every VTT to a clean, timestamped, speaker-labeled TXT file.

Windows 10/11 Requires Microsoft Edge (Conditional Access) ~23 MB installer Bundled Node runtime — no separate install
Download ExtractTranscript-Setup.exe

Silent lab/unattended install: ExtractTranscript-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Relabel Downloads

Scans a folder (or a single file) for Office documents carrying a Confidential / Highly Confidential Microsoft Purview sensitivity label and relabels them to General, so tools like Copilot can open and reason over them. Drives the real Office ribbon "Sensitivity" control via UI Automation and answers the mandatory justification prompt automatically — skips files that are already open, locked, or already at a General/Public/Non-Business label.

Windows 10/11 Requires Word / PowerPoint / Excel installed Requires Microsoft Purview sensitivity labels ~2 MB installer
Download RelabelDownloads-Setup.exe

Silent lab/unattended install: RelabelDownloads-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Both installers are self-contained (Inno Setup, per-user install, no admin rights required) and create Start Menu / optional Desktop shortcuts on first run. Links are Microsoft/OD4B-gated — sign in with a Microsoft work account to download.
